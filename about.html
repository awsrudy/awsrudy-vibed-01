About AWS Blog Scraper

What is this?

AWS Blog Scraper is an automated tool that aggregates blog posts from multiple official AWS blogs into a single, searchable archive. This project makes it easier to discover and explore AWS content across different blog sources.

How It Works

  1. Scraping: Python scraper fetches posts from RSS feeds daily
  2. Processing: Content is cleaned, AWS services are detected, reading time is calculated
  3. Storage: Posts are stored in JSON format with rich metadata
  4. Search: Pagefind creates a client-side search index
  5. Display: Jekyll builds a static site hosted on GitHub Pages

Technology Stack

  • Jekyll 4.3.3 - Static Site Generator
  • Python 3.11 - Scraper
  • Pagefind - Search
  • GitHub Actions - Automation
  • GitHub Pages - Hosting

Features

  • Daily automated scraping of AWS blog posts
  • Full-text search powered by Pagefind
  • Filter by source, AWS service, and content type
  • Responsive design with AWS branding
  • Dark mode support
  • Reading time estimates
  • AWS service detection and tagging
  • Code snippet detection
